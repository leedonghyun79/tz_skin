# Phase 0 진단 — tvzonemall.com (2026-09-15)

## 점검 방법
크롤러 시점(JS 미실행) 기준으로 curl 검증. 카페24 프리티 URL(/category/.../25/)이 실제로는
product/list.html?cate_no=25 를 내부 리라이트한 것인지, canonical이 올바른지부터 확인.

## 점수표

| 레인 | 상태 | 근거 |
|---|---|---|
| SEO 기본기 | ✅ | title(30자대)·meta description(50자대)·canonical·JSON-LD 1건·sitemap.xml(200) 모두 정상 |
| URL 구조 | ✅ | /category/.../25/ 는 정상 200, canonical도 동일 URL로 자기참조 — 프리티 URL이 올바른 정규 URL |
| robots.txt | ⚠️ | `Sitemap:` 지시어가 `https://www.tvzonemall.com/sitemap.xml`(www)를 가리키는데, 실제 canonical·sitemap 본문은 전부 `tvzonemall.com`(non-www) — 도메인 불일치 |
| www/non-www 중복 | ⚠️ | www와 non-www 둘 다 200 응답, 서로 리다이렉트 없음 (301/302 미설정) → 중복 콘텐츠로 크롤링될 위험 |
| 404 처리 | ✅ | 존재하지 않는 URL 요청 시 정상 404 |
| GEO(llms.txt) | ✅ | /llms.txt 200, 쇼핑몰 구조 설명 포함 |
| AEO/구조화데이터 | ⚠️ | JSON-LD 1건뿐 — 상품/카테고리 페이지에 Product, BreadcrumbList 등 스키마 확장 여지 있음 (미검증, 홈만 확인) |

## 우선순위 제안

1. **[중요] www → non-www 301 리다이렉트 설정.** 지금은 두 도메인이 각각 다른 content-length로
   200을 반환 중(중복 콘텐츠). 카페24 관리자 > 도메인 설정에서 www를 기본도메인으로 리다이렉트
   처리해야 함. 코드 수정이 아니라 카페24 관리자 콘솔 설정 영역이라 직접 반영은 불가 — 안내만 가능.
2. **[사소] robots.txt의 Sitemap 지시어를 non-www로 통일.** 현재 `skin7/robots.txt`,
   `mobile5/robots.txt` 파일에서 `Sitemap: https://www.tvzonemall.com/sitemap.xml` →
   `https://tvzonemall.com/sitemap.xml` 로 수정 권장 (canonical/sitemap 본문과 일치시키기 위함).
3. **[선택] 카테고리/상품 상세 페이지 JSON-LD(Product, BreadcrumbList) 확장.** 홈 외 페이지는
   미검증이므로 별도 진단 필요.
